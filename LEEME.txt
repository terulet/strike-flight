===========================================
  PLAYZONE
===========================================

Todos los juegos en un sitio. Doble clic en
index.html y desde ahi se llega a todo.

  EL CATALOGO
-------------------------------------------

  001  FLIGHT STRIKE          (en MAX)
  002  ONE MORE FLOOR

siguiente juego que hagamos es el 008.


-------------------------------------------
  LAS DOS ZONAS
-------------------------------------------

PLAYZONE      -> la portada y el catalogo

                 carpeta max\. Ahi vive
                 Flight Strike.


-------------------------------------------
  OJO CON EL DOBLE CLIC
-------------------------------------------

Con doble clic funcionan los juegos de un
solo archivo: 001, 004, 005, 006 y 007.

El 002 y el 003 estan hechos con modulos y
el navegador no los deja abrir asi. Traen su
propio servidor:

  002 -> npm start
  003 -> npm run dev

Subido a GitHub Pages funciona todo sin
tener que hacer nada de esto.


-------------------------------------------
  ANADIR UN JUEGO
-------------------------------------------

Abre index.html con el Bloc de notas. Arriba
del todo esta la lista CATALOGO. Copias una
linea, cambias los datos y recargas.

Poniendo listo:false la casilla sale en gris
con un "en construccion". Sirve para reservar
el hueco sin romper nada.
